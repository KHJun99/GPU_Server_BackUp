## 3. 핵심 발견

- **Reach 한계: x ≥ 0.35는 절대 불가능**. SO-ARM101의 ee 도달 거리가 ~0.32m 정도.
- **Reach는 광범위, grip은 좁음**: LIFT 도달 가능 영역(x ∈ [0.15, 0.31], y ∈ [-0.12, +0.12])과 12cm 성공 영역(x ∈ [0.23, 0.31], y ∈ [0, +0.08])이 큰 차이. **잡았다 놓침이 진짜 병목**.
- **너무 가까우면 잡지 못함**: x ≤ 0.19, y = 0이면 LIFT 도달은 100%지만 12cm 0%. Robot base와 거리 짧으면 gripper 접근 각도가 cube에 맞지 않음.
- **+y 편향**: 12cm 성공 영역이 +y에 치우침. (0.23, +0.04) 100%지만 (0.23, -0.04)는 38%. Finger offset 또는 default arm pose의 비대칭 추정.
- **Sweet spot 4점**: (0.23, +0.04), (0.23, +0.08), (0.27, 0), (0.31, 0) → 12cm 75~100%.

## 5. 다음 step

2. **+y 편향 원인 진단** (선택, 30분) — finger offset(`finger_x_offset = +0.006`) 또는 default arm pose `wrist_flex=1.57` 이 cause인지. Oracle config 만져서 -y 영역도 grip 성공하게 가능한지.

## 6. 보조 정보

- (0.23, ±0.04~0.08) 영역에서 12cm 성공률 차이 (+: 100%, -: 38%)는 통계 노이즈일 수도 있음. 8 env/point만이라 ±15%pt 분산 가능. dense 측정 필요.
- (0.190, -0.120)에서 LIFT 100%지만 12cm 0%: cube 끝단 위치에서 gripper 닿지만 잡지 못함. 모서리 영역은 spawn에서 제외.
- max_z median 0.048 ≈ cube spawn z. 절반 이상 env에서 cube가 움직이지도 않음 (12cm 성공률 매우 sparse).
